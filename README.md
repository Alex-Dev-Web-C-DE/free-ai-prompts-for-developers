## 🧠 The Prompts

### 1. Code Review
> Act as a senior software engineer. Review the following code for performance, security, and readability. Suggest specific improvements with code snippets.

### 2. Bug Fixing
> I have a bug in my code. Here is the code and the error message. Explain why this happens and give me the fixed version.

### 3. Regex Generator
> Write a regex that matches [describe what you need]. Explain how it works and provide 3 test cases.

### 4. SQL Query Optimization
> Here is my SQL query and the database schema. Optimize this query for speed and explain the changes.

### 5. Architecture Design
> I want to build [describe your app]. Suggest a scalable architecture using modern tools. Include a diagram and a list of pros/cons.

### 6. Refactoring to Functional
> Refactor this code to be more functional and readable. Remove side effects and improve testability.

### 7. Explaining Complex Code
> Explain this code to me like I'm a junior developer. Break it down line by line.

### 8. Unit Test Generator
> Write unit tests for this function using [Jest/PyTest/etc.]. Cover edge cases.

### 9. Tech Stack Comparison
> Compare [Tech A] vs [Tech B] for building [your project]. Give me a clear recommendation.

### 10. Documentation Writer
> Write comprehensive documentation for this API endpoint, including parameters, responses, and error codes.
